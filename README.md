# Дейлик

Планировщик задач для тех, у кого мало сил: таймлайн дня, сферы жизни, напоминания. Работает локально в браузере, ставится как приложение (PWA), данные не покидают устройство.

Онлайн: https://trueruff.github.io/daylikPROD/

## Возможности

- Таймлайн дня со свободными окнами, перетаскиванием дел и шкалой занятости недели
- Быстрый ввод одной строкой: система сама определяет тип записи (дело, практика, сфера) — правила + LLM с фолбэком на правила
- Автокладка: раскладывает дела по свободным слотам с превью до применения
- Сферы жизни в трёх группах (быт, желания, практики) с цветовым кодированием
- Напоминания через Web Notifications
- Учётные записи и журнал событий (данные — в IndexedDB, пароли — PBKDF2)

## Стек

TypeScript, Vite, Dexie (IndexedDB), Vitest, Service Worker (PWA). Интерфейс — ванильный DOM без фреймворков.

## Запуск

```
npm install
npm run dev      # разработка
npm test         # тесты
npm run build    # сборка в dist/
```

Ключ LLM кладётся в `app/.env` (см. `app/.env.example`) — без него разбор ввода работает по правилам.
